# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [2.0.0] - 2026-07-11
### Added
- In-app update notification banner to alert users when a new version is available on GitHub.
- Silent background check that compares the local version with the remote `manifest.json`.

### Changed
- Refactored `popup.html` and `popup.css` to accommodate the new update banner seamlessly into the UI (including dark mode support).

## [1.0.0] - Initial Release
### Added
- Core functionality to bulk-remove saved posts, reels, and videos from Facebook.
- Real-time live progress tracking.
- Safe, Balanced, and Fast speed controls.
